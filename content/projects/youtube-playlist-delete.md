## Overview
YouTube removed the Trash icon from playlists and replaced it with a dropdown menu. The new behavior requires users to press twice to remove a video, which is tedious when managing large playlists.
This Stylus CSS style repositions the dropdown menu slightly upwards, allowing you to **double-click to remove a video** from a playlist in one smooth action.
---
## Features
- **Double-click removal** — No more clicking twice on different elements
- **Lightweight** — Pure CSS solution, no JavaScript
- **Stylus-based** — Easy to install and toggle on/off
---
## Installation
1. Install the [Stylus browser extension](https://add0n.com/stylus.html)
2. Create a new style for [`youtube.com`](http://youtube.com)
3. Paste the CSS from `stylus.css`
4. Save and enable
