### Overview
This script allows you to toggle a whole new set of keyboard binds with a press of a button. Each keypad key can have **2 different binds** — the main binds (default) and the alt set of binds.
Covers every keypad key except Num Lock.
### How It Works
- **Main binds** — Active when TooMaNyBiNds is off
- **Alt binds** — Active when TooMaNyBiNds is on
- Toggle between sets with a single key press
### Installation
1. Place the script into `autoexec.cfg`
2. Edit the **"Binds"** section to customize your commands
3. Replace `"KEY"` with your desired toggle key
